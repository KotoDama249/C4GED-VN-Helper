VN Script Weaver

Builds a .gd dialogue script matching the format needed for the Scripted / VNChar / VNOption framework. This helps write the dialogue script.

Load Existing Script

Reads a .gd file in the same shape as this tool's output, or a hand-written script, back into the editor.

Characters

Backgrounds

Same one-spritesheet-of-named-variants pattern as a character's face, but shown in the single shared background slot instead of left/center/right. A CG is just a background shown with no characters entered.

Asset Paths

Set a shared folder path, e.g. prefix res://art/ + path akisa_sheet.png. A path that already starts with res:// or user:// ignores its prefix. Separate prefix fields for spritesheets and scripts.

Output File

The name of the saved file when hitting "Download" after generating the script.

Project

Save your characters + sequence as a project file so you can reopen and keep editing it later, or use it as a starting point for a new scene.
